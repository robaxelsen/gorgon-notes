## Known limitations / caveats
- Sessions spanning midnight are split (chat logs are per day).
- Storage `used` counts are only as fresh as the last Storage export.
- Vendor remaining is an estimate from the last Character export; selling after the export isn't reflected (no live vendor gold on Mac).
- Phone screenshots: headless Chrome's `--window-size` cannot go below about 500 px on macOS, so a `--window-size=390` shot looks clipped on the right on every view; that is the tool, not the page. Use CDP device emulation (the taste-skill `lib/cdp.mjs` `newPage({width: 390, height: 844, dsf: 2, mobile: true})`, as `design/screenshots/*-390-*.png` were taken) and check `scrollWidth == innerWidth`.
- Restarting the server: kill by port, `lsof -ti tcp:8787 | xargs kill` (`pkill -f` didn't match the Homebrew Python process name).
